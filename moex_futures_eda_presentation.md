## 2. Что показывать на презентации

Рекомендуемый порядок демонстрации:

1. **Открыть Streamlit app** — <https://moex-futures-eda.streamlit.app>.
2. **Показать структуру проекта через sidebar** — слева видно, что проект разбит на логические разделы EDA.
3. **Пройти по разделам** (по порядку из sidebar):
   - **Abstract** — краткое описание проекта и цели.
   - **Dataset Description** — что за данные, источник, объём, поля.
   - **Data Cleaning** — как чистили и агрегировали данные.
   - **Descriptive Statistics** — основные статистики по инструментам.
   - **Basic Plots** — базовые графики (цена, объём, доходность).
   - **Detailed Overview** — углублённый разбор по инструментам.
   - **Hypothesis Testing** — проверка гипотез на данных.
   - **Discussion / Conclusion** — обсуждение и выводы.
4. **Открыть Swagger docs** — <https://moex-eda-api.onrender.com/docs>.
5. **Показать основные API endpoints**:
   - `GET /` — корень сервиса / health-check, базовая информация об API.
   - `GET /symbols` — список доступных инструментов (тикеров).
   - `GET /data?symbol=IMOEXF&limit=10` — строки аналитического датасета по инструменту.
   - `GET /stats/IMOEXF` — агрегированная статистика по инструменту.
   - `POST /data` — добавление новой записи (демонстрация записи через API).
6. **При необходимости показать GitHub repository и README** — структура проекта, инструкции, публичные ссылки, скриншоты.

> 💡 Совет: держите вкладки Streamlit и Swagger открытыми **заранее**, чтобы не ждать «холодного старта» Render во время выступления.

## 5. Что говорить про датасет

- Данные относятся к **срочному рынку Московской биржи** (FORTS).
- Анализируются **фьючерсные сделки** по ликвидным инструментам.
- **Исходная строка** сырых данных — это **отдельная сделка** (trade).
- **Итоговая строка** аналитического датасета — это **один инструмент за один торговый день** (агрегат).
- Основные поля аналитического датасета:
  - **цена** (open/high/low/close);
  - **объём** (volume);
  - **количество сделок** (trades count);
  - **открытый интерес** (open interest);
  - **доходность** (return);
  - **волатильность** (volatility);
  - **buy/sell activity** (соотношение покупок и продаж).

> Ключевая мысль: мы перешли от **сотен миллионов отдельных сделок** к компактному и обозримому **дневному** датасету, сохранив всю важную структуру для анализа.

## 6. Что говорить про гипотезы

Кратко формулируем гипотезу → говорим результат.

1. **Более ликвидные фьючерсы имеют меньшую волатильность.**
   - **Результат:** гипотеза **не подтвердилась** (или подтвердилась очень слабо) — корреляция между ликвидностью и волатильностью близка к нулю.

2. **В дни сильных ценовых движений торговая активность выше.**
   - **Результат:** гипотеза **подтвердилась** — в дни больших движений цены объём и количество сделок заметно выше.

3. **В дни высокой волатильности дисбаланс buy/sell выше.**
   - **Результат:** гипотеза **подтвердилась умеренно** — связь есть, но выражена не очень сильно.

> Главное при защите: показываем, что **каждый вывод подкреплён цифрами** (корреляции, сравнения групп), а не интуицией.

## 8. Возможные вопросы преподавателя и короткие ответы

- **Что такое фьючерс?**
  Стандартизированный биржевой контракт на покупку/продажу базового актива в будущем по заранее зафиксированной цене.

- **Что такое open interest?**
  Открытый интерес — количество открытых (ещё не закрытых) фьючерсных позиций; показывает, сколько контрактов реально «живёт» на рынке.

- **Почему использовали агрегированный дневной датасет?**
  Сырые данные — это сотни миллионов отдельных сделок, их слишком много для прямого анализа. Агрегация до «инструмент × день» делает данные обозримыми и сохраняет ключевую структуру.

- **Почему выбрали эти инструменты?**
  Это наиболее ликвидные фьючерсы FORTS: по ним достаточно данных, и они репрезентативны для рынка.

- **Что показывает normalized close?**
  Цену закрытия, приведённую к общему базовому уровню (нормированную), чтобы сравнивать динамику разных инструментов в одном масштабе.

- **Что такое volatility?**
  Волатильность — мера изменчивости цены (как правило, стандартное отклонение доходностей): чем выше, тем сильнее колебания.

- **Что такое Streamlit?**
  Python-фреймворк для быстрого создания интерактивных web-приложений прямо из скриптов анализа данных.

- **Что такое FastAPI?**
  Современный Python-фреймворк для создания REST API с автоматической документацией и валидацией данных.

- **Зачем нужен Swagger?**
  Swagger UI — это интерактивная документация API: показывает все endpoints и позволяет тестировать запросы прямо в браузере.

- **Чем web interface отличается от notebook?**
  Notebook — это среда для разработки и воспроизведения анализа (с кодом). Web interface (Streamlit) — готовый публичный продукт, где результаты видны без кода и без запуска.
